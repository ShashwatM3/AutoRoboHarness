# AutoRoboHarness

A self-improving harness for a fleet of store robots, built at the Recursive Agents Hackathon (Crusoe x Cerebral Valley, October 17, 2026).

Start with the planning and context documents in [AUTO-ROBO-SIM-FILES/INDEX.md](AUTO-ROBO-SIM-FILES/INDEX.md): [DECISIONS.md](AUTO-ROBO-SIM-FILES/DECISIONS.md) for what is locked, and [BUILD-PLAN.md](AUTO-ROBO-SIM-FILES/BUILD-PLAN.md) for who builds what, in which order.

## Setup

Copy `.env.example` to `.env` and fill in the keys. `.env` is git-ignored and must never be committed.
